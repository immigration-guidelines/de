# Immigration guidance: Germany (federal level and states)

Published guidance that the authorities of Germany (federal level and states) issue to the officials who decide immigration cases, collected in November 2026.

- **Guidance:** 812 files in this folder. `index.tsv` lists each file with its title, date and source address.
- **Country-of-origin reports:** 871 files in `coi/`, with their own `coi/index.tsv`.
- The files are unmodified copies of what the source published. Where a source refused automated access, copies come from a public web archive; the index says which.
- What is missing, and how to obtain it, is described in [MISSING.md](https://github.com/immigration-guidelines/.github/blob/main/MISSING.md), in the repository that also holds the download scripts. Other jurisdictions are listed on the [organisation page](https://github.com/immigration-guidelines).

**Berlin.** The Berlin immigration office's guidance (Verfahrenshinweise zum Aufenthalt in Berlin, VAB) is in [`berlin/`](berlin/): the source PDF of every known version from 2007 to 2026, 79 in all. The text of those versions, as a history with one commit and one tag per version so that changes can be read as diffs, is kept separately at [immigration-guidelines/berlin_vab](https://github.com/immigration-guidelines/berlin_vab). The `berlin/` folder is not listed in the top-level `index.tsv`; it has its own.

The documents remain the work of the authorities that published them.
